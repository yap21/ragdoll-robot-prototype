러그돌 로봇 블록 퍼즐 – 월드 1 프로토타입 (Phaser 3.80.1 + Matter.js)

실행 방법
  1) 이 폴더에서:  python3 -m http.server 8765
  2) 브라우저에서:  http://localhost:8765/   (휴대폰은 같은 Wi‑Fi에서 PC의 IP:8765)
  * index.html을 파일로 바로 열어도 대부분 동작하지만, 로컬 서버를 권장해요.

옵션
  ?unlock  모든 스테이지 잠금 해제
  ?debug   Matter 물리 디버그 표시
  ?z=1|1.5|2  렌더 해상도 배율 고정(기본: 화면 폭×DPR에 맞춰 1~2 자동)

조작: 나무 블록/폭탄을 탭해서 없애요. 돌(모서리 볼트)은 없앨 수 없어요.
목표: 로봇이 민트 매트 위에서 1.5초 동안 멈춰 있으면 클리어.
별: 쓴 탭 수로만 결정돼요. 몸통 주스 게이지가 별 페이스를 보여 줘요.

[새 기능 v2]
1) 순서 규칙 (1-2 "순서가 중요해")
   - 블록에 1·2·3 숫자 배지가 붙어 있고, 지금 빼야 할 블록 배지는 주황색으로 깜빡여요.
   - 순서가 틀린 블록을 탭하면: 블록은 빠지지 않고(탑이 무너지지 않음) 탭 +1 벌칙.
     빨간 ✕, "탭 +1" 표시, 화면 흔들림, "순서가 틀렸어요!" 안내가 나와요.
   - 1번 틀리면 별 2개, 2번 틀리면 별 1개(탭 한도 6).
2) 슬로모션 리플레이
   - 클리어/실패 결과 화면의 "리플레이" 버튼.
   - 마지막 탭 직전부터 착지(또는 실패) 0.8초 뒤까지(최대 약 4.4초)를 0.45배속으로 재생.
   - 화면을 탭하면 바로 결과 화면으로 돌아가요. 재생 중 물리는 일시정지되고 실제 상태는 그대로예요.
3) 힌트 화살표
   - HUD 오른쪽 위 "힌트" 버튼: 다음에 뺄 블록을 가리키는 화살표(약 4초) + 글 힌트.
   - 순서 스테이지에서는 다음 정답 블록을 가리켜요.
   - 비용: 별/탭은 깎이지 않는 대신 스테이지마다 2번까지(버튼 위 숫자). 다 쓰면 글 힌트만 보여요.
     결과 화면에 사용 횟수가 표시돼요.

[v3 – 단일 캐릭터 + 고급 그래픽]
1) 로봇을 하나의 객체로 단순화
   - 래그돌 관절 대신 몸통+머리 2파츠 복합 강체(Body.create parts) 1개, 스프라이트 1장.
   - LED 표정 유지: 기본/깜빡임, 낙하 중 겁먹음, 어지러움(머리 충돌), 기쁨(클리어), 슬픔(실패).
   - 스쿼시&스트레치, 귀 스프링 흔들림, 주스 출렁임은 코드로 연출.
   - 물리: 몸통 밀도 0.0032 / 머리 0.0012(저중심 → 잘 서 있음), 마찰 0.85, 정지마찰 1,
     공기저항 0.012, 반발 0.02. 폭탄 충격 k = 8×(1−d/R)+4.5를 단일 바디에 적용.
   - 게임 로직은 고정 dt(1/60초)로 돌아서 프레임이 떨어져도 결과가 같아요.
2) 컨셉 디자인 톤의 그래픽
   - 모든 텍스처를 2배 해상도 절차 생성(외부 이미지 없음): 베벨/그림자 블록(나무결, 돌+볼트),
     마카롱 쿠션 매트, 반짝이는 폭탄 심지.
   - 패럴랙스 배경: 하늘 그라데이션, 해, 흘러가는 구름, 회전하는 관람차, 언덕, 바닥 타일.
   - 파티클: 나무 조각, 먼지, 연기, 불꽃, 컨페티, 민트 반짝이, 말풍선.
   - 광택 HUD/버튼/결과 패널(리본, 별 연출), 한글 폰트 Jua 내장(assets/jua.woff, 서브셋).
